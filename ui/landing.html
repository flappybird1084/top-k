    Check 1

    Compiles

    Built in a CPU process pool, off the GPU’s critical path, and cached by source.

    Check 2

    Matches eager

    Outputs and gradients against PyTorch eager, on common shapes plus one it has never seen.

    Check 3

    Faster alone

    Re-timed against the current best in the same session. Inputs rotate, so it can’t memorize.

    Check 4

    Faster in the step

    Timed inside a real training step, interleaved with the incumbent. Within noise counts as no.

    The checks are tested too: two planted cheating kernels, one that caches its outputs and one that hard-codes shapes, go through them before every run. If either passes, the run aborts.
